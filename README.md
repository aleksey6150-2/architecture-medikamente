# Решение задание спринта 10

## Задание 1

Главная находка по As-Is — данные лежат вплотную к пользователям и защищены только доменной аутентификацией: нет шифрования, нет аудита, нет разграничения доступа. Самое острое — ПДн (ФИО пациентов и врачей) торчат прямо в именах файлов и папок (Pacient1-FIO-BD, Journal-Doctor-FIO), то есть утекают ещё до открытия файла. Категории данных не разделены — медицинские, финансовые и административные свалены на одном диске, а ресепшен по факту суперюзер с доступом к медкартам. Privacy by Design отсутствует, минимизация нарушена (избыточные поля, дубли Excel+1С, бэкапы, выгрузки аналитика на сырых ПДн), Data Lineage и реестра обработки нет вообще. По CIA проседают все три плеча. Ключевой приём, который примиряет цель «копить данные для ML» с минимизацией: операционный контур работает с зашифрованными/псевдонимизированными данными, аналитический (ClickHouse) — только с обезличенными.

Data flow diagram построены по четырём процессам: запись на приём, ведение медкарты, обработка анализов, приём и процессинг платежей. В target-версии на тех же потоках показаны шифрование и теги на хранилищах, AuthZ и аудит на процессах, TLS и минимизация на входах, обезличивание на потоке в аналитику и границы доверия.
